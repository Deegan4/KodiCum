v1.1.0 (2026-08-04)
- Device discovery: find DLNA/UPnP MediaRenderers (smart TVs, AV receivers,
  streaming sticks) on the local network via an SSDP M-SEARCH, listed with
  their manufacturer, model and IP address
- Only devices exposing an AVTransport service are listed, so media servers,
  printers and routers are filtered out
- Scan results are cached for a configurable few minutes, with a "Scan again"
  item and a "Scan for devices now" settings button
- New settings: enable/disable discovery, discovery timeout, result lifetime

v1.0.2 (2026-07-21)
- Adaptive streaming: HLS/DASH/SmoothStreaming via InputStream Adapter, with
  optional Widevine/PlayReady DRM (license_type/license_key from /resolve)
- Quality selection: choose Ask / Best / a preferred resolution when the
  source returns multiple streams (new "streams" resolve shape)
- Response caching with a configurable TTL for categories and listings
- Automatic retry-with-backoff on transient network errors
- Skin widget endpoints (?action=widget&type=favorites|history|category)
- "Test connection" settings button and a "Clear content cache" action

v1.0.1 (2026-07-21)
- Latest-Kodi compatibility: video metadata now uses the InfoTagVideo API on
  Kodi 20+ (Nexus/Omega), falling back to setInfo on Kodi 19 (Matrix)
- Removed the unused beautifulsoup4 dependency (only requests is used), so the
  add-on installs cleanly on current Kodi

v1.0.0 (2026-07-21)
- Initial release
- Category browsing with pagination
- Search with persistent search history
- Favorites (add / remove / clear) with context menus
- Watch history tracking
- Resume points for partially watched items
- Configurable JSON content source, user-agent and page size
- Maintenance actions to clear search/watch history and resume points
- Reference mock backend and off-device unit test suite
